# Crew Heat Implementation Plan (Street Rules — Pillar 2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Per-team momentum meter — big plays build heat, big defensive plays steal it, a full bar puts the crew ON FIRE (juiced kicks, faster fielders, laser throws, flame VFX) for a few plays. Spec: `docs/superpowers/specs/2026-07-16-street-rules-design.md` pillar 2.

**Architecture:** Headless `CrewHeat` (`src/game/crewHeat.js`) owns values, the event→gain/steal table, fire state, and modifier getters. matchScene feeds it from ONE channel per event type — `match.bus 'play'` labels for rules-engine outcomes, scene call sites for scene-only events (PERFECT, robbed catch, peg, pickle results, double plays) — and multiplies its modifiers into the same spots City Elements already touch. HUD gets slim heat bars under the score bug.

**Tech Stack:** Vanilla JS, vitest. Same conventions as pillar 1.

## Global Constraints

- One channel per event — never count the same play twice (e.g. homerun arrives via `match.bus 'play'`; do NOT also add heat at `homer()`).
- Fire affects the WHOLE crew both ways (kicking: power; fielding: speed + throws).
- Heat modifiers COMPOSE with element modifiers (multiply, never replace).
- No per-frame DOM churn: HUD heat refresh throttled to ~4 Hz.
- Headless engine: seedable, no three.js/DOM imports, unit-tested.

### Task 1: CrewHeat engine + tests

**Files:**
- Create: `src/game/crewHeat.js`
- Test: `tests/crewHeat.test.js`

**Interfaces (produces):**
- `HEAT_EVENTS` table: `{ PERFECT:{gain:15}, double:{gain:12}, triple:{gain:18}, homerun:{gain:30}, steal:{gain:10}, strikeout:{gain:12,steal:6}, catch:{gain:8,steal:4}, 'caught-stealing':{gain:15,steal:10}, doubleplay:{gain:25,steal:15}, robbed:{gain:22,steal:15}, peg:{gain:15,steal:8}, pickleWin:{gain:25,steal:15}, pickleEscape:{gain:25,steal:10} }`
- `class CrewHeat`:
  - `value = {home,away}` (0–100), `add(side, evt)` → applies gain to `side` + steal from the other side; returns `'ignited'` when the bar crosses 100 (sets fire, once per ignition)
  - fire: `firePlays = {home,away}` — ignition sets 4; `notePlay()` decrements BOTH sides' counters by 1 (a play is a play); expiry resets that side's value to 25
  - `onFire(side)` → bool; `update(dt)` passive decay 0.35/s (skipped while that side is on fire)
  - Modifiers: `kickPowerMult(side)` 1.12 on fire else 1; `fielderSpeedScale(side)` 1.12 on fire else 1; `throwSpeedScale(side)` 1.15 on fire else 1

Steps: write failing tests (gain, steal floor at 0, ignition returns 'ignited' exactly once, fire expiry after 4 notePlay → value 25, decay pauses during fire, modifiers flip with fire), run (fail), implement, run (pass), commit.

Test sketch (complete assertions in the file):

```js
import { CrewHeat, HEAT_EVENTS } from '../src/game/crewHeat.js';
it('gains and steals', () => {
  const h = new CrewHeat();
  h.add('home', 'homerun');           // +30
  expect(h.value.home).toBe(30);
  h.add('away', 'doubleplay');        // away +25, steals 15 from home
  expect(h.value.away).toBe(25);
  expect(h.value.home).toBe(15);
});
it('ignites once at 100, burns 4 plays, resets to 25', () => {
  const h = new CrewHeat();
  for (let i = 0; i < 3; i++) h.add('home', 'homerun');
  expect(h.add('home', 'homerun')).toBe('ignited');
  expect(h.onFire('home')).toBe(true);
  expect(h.kickPowerMult('home')).toBeGreaterThan(1);
  for (let i = 0; i < 4; i++) h.notePlay();
  expect(h.onFire('home')).toBe(false);
  expect(h.value.home).toBe(25);
});
it('decays over time but not while on fire', () => { /* update(10) drops value; ignited side holds */ });
```

### Task 2: matchScene wiring

**Files:**
- Modify: `src/game/matchScene.js`

- Construct `this.heat = new CrewHeat()` beside `this.elements`; RE-CREATE in `startMatch()` (rematch resets momentum) and subscribe there:
```js
this.match.bus.on('play', ({ type, side }) => {
  const def = side === 'home' ? 'away' : 'home';
  if (['double', 'triple', 'homerun', 'steal'].includes(type)) this.noteHeat(side, type);
  else if (['strikeout', 'caught-stealing'].includes(type)) this.noteHeat(def, type);
  else if (type === 'catch' || type === 'foulout') this.noteHeat(def, 'catch');
  this.heat.notePlay();
  this.refreshHeatHud();
});
```
- `noteHeat(side, evt)` helper: `add()`, and on `'ignited'` → `hud.call(teamShort(side).toUpperCase() + ' ON FIRE!', 'crowned')`, `bus.emit('sfx','crowd-cheer')`, `bus.emit('vo','fire')` (graceful no-op), `field.crowdEnergy = 1`.
- Scene-only feeds (one line each, at the existing sites):
  - PERFECT: beside `special.add('PERFECT')` (line ~790) but side-aware and for BOTH human/AI: `this.noteHeat(this.match.kickingSide(), 'PERFECT')` — place it OUTSIDE the `kickingIsPlayer()` gate.
  - Robbed catch: where `cine:robbed` is emitted (2 sites ~2563/2599): `this.noteHeat(this.match.fieldingSide(), 'robbed')`.
  - Peg: beside `special.add('peg')`: `this.noteHeat(this.match.fieldingSide(), 'peg')`.
  - Pickle: in `endDuel()` — escape branch (beside `special.add('pickleEscape')`): offense `pickleEscape`; tagged branch: defense `pickleWin`.
  - Double play: in `finalizePlay` where `outsAdded >= 2` calls it out: `this.noteHeat(this.match.fieldingSide(), 'doubleplay')`.
- Modifier application (compose with elements):
  - Kick: in `attemptKick`, `powerMult *= this.heat.kickPowerMult(this.match.kickingSide())` right after the special-meter block; while on fire also `igniteBall(this.ball)` at `onKickContact` for non-FOUL contact (reuse the fire look; `douseBall` already runs at the next serve).
  - Fielders: in `fielderSpeed()`, multiply by `this.heat.fielderSpeedScale(this.match.fieldingSide())`.
  - Throws: in `throwSpeed()`, multiply by `this.heat.throwSpeedScale(this.match.fieldingSide())`.
- Decay + HUD: in `update()`, `this.heat.update(rawDt)`; `refreshHeatHud()` throttled to 250ms (`this._heatHudAt`).
